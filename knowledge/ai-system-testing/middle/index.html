Documentation and testing process

How should CI/CD suites be structured?Middle

Answer

PR: unit, schema, prompt rendering, mocked tools and small critical evals. Merge: integration with real test dependencies. Nightly: broader golden sets, robustness and repeated runs. Release: risk slices, security, load and human review. Production: monitoring/canary. Define separate budgets and gates.

Primary sources

  • S27: ISTQB Glossary (reviewed 2026-10-06)
How can regression be optimized in a large project?Middle

Answer

Map changes to risks and coverage, remove duplicates, isolate flaky tests, separate fast and costly suites and isolate parallel data. Retain critical smoke and periodic full runs. For AI cache only where it cannot hide model changes; version cache keys and datasets.

Primary sources

  • S27: ISTQB Glossary (reviewed 2026-10-06)
Which test techniques are useful for AI?Middle

Answer

Use equivalence classes for languages/roles/tasks, boundaries for context and tool limits, decision tables for policies, state transitions for agents and pairwise for configurations. Metamorphic tests check expected relations; adversarial tests probe robustness. Property-based tests check invariants; justify every relation.

Primary sources

  • S27: ISTQB Glossary (reviewed 2026-10-06)
How do bias and fairness testing differ from adversarial testing?Middle

Answer

Bias is systematic skew; fairness assesses whether group differences are justified under a defined criterion. Adversarial testing deliberately perturbs inputs to induce undesired behaviour. They overlap but have different objectives. Fairness metrics and groups must match the task context.

What makes a test case genuinely useful?Middle

Answer

A useful test case has a clear purpose, controlled preconditions and data, unambiguous actions, an observable expected result, and a link to a risk or requirement. It should be detailed enough for its audience without restating the obvious or hiding the oracle in long prose.

  • For an AI case, record versioned input/context, acceptable alternatives, prohibited claims, the rubric, model/prompt/data versions, and required evidence.

What information belongs in a good defect report?Middle

Answer

A report should let others understand, reproduce, and assess the problem: a factual summary, version and environment, preconditions and data, minimal steps, actual and expected results, reproducibility, impact, evidence, and related artefacts. Severity describes impact; priority describes urgency.

  • For an AI defect, add the prompt, model, retrieval snapshot, parameters, and repeatability without storing secrets or unauthorised personal data.

Why should severity and priority remain separate?Middle

Answer

Severity estimates the scale and nature of a defect’s impact on the product, user, or data. Priority represents business repair order considering deadlines, reach, workarounds, and cost. High severity does not always mean first to fix, while a low-severity issue can be urgent in its business context.

  • A low AI-failure frequency does not reduce the severity of data leakage or an unauthorised action; assess harm separately from reproducibility.

Examples

  • A rare crash in an admin tool may have high severity but lower priority; a homepage typo before a campaign can show the opposite pattern.

  1. Provide four high/low severity and priority combinations and justify each with context.
What do entry, exit, and suspension criteria provide?Middle

Answer

These criteria guide decisions rather than automatically guaranteeing quality:

  • Entry criteria define when a test activity is ready to start.
  • Exit criteria define the evidence needed to finish it or make a decision.
  • Suspension criteria define when continuing would produce unreliable results or waste resources.
  • AI entry and exit criteria should name versioned datasets, the oracle/rubric, approved thresholds, repeated runs, and owners of critical residual risks.

Primary sources

  • S27: ISTQB Glossary (reviewed 2026-10-06)

Examples

  • If the environment is unstable and half of the API requests fail because of infrastructure, a suspension criterion prevents the team from drawing false conclusions.

Practice exercises

  1. Define entry, exit, and suspension criteria for a short regression cycle and name the owner of exceptions.
How does risk-based testing help set priorities?Middle

Answer

The team connects testing depth and order to the likelihood and impact of a problem while considering change complexity, defect history, data criticality, observability, and recovery cost. It is not a magic formula but a transparent way to discuss constraints.

  • AI risk analysis accounts for oracle ambiguity, labelling effort, model/provider changes, repeated runs, access boundaries, and harm from incorrect tool actions.

Primary sources

  • S27: ISTQB Glossary (reviewed 2026-10-06)

Examples

  • A small invoice-format change may carry high risk when many customers need that document for tax reporting.

Answer

What are lambda, args and kwargs?Middle

Answer

lambda creates a function with one expression, such as key=lambda x: x.score. *args collects positional arguments into a tuple and **kwargs named arguments into a dict; in calls they unpack collections. Prefer def and explicit signatures for complex logic.

Answer

How does import work and how does from import differ?Middle

Answer

import module binds the module name; from module import name binds the selected object. On first import Python locates and executes a module and normally caches it in sys.modules. Side effects, circular imports and binding time matter; mock where the dependency is looked up.

How are generators, decorators and context managers implemented?Middle

Answer

A generator uses yield; a function decorator returns a wrapper and uses functools.wraps; a context manager implements __enter__/__exit__ or @contextmanager with try/finally around yield. Test exception paths, cleanup, preserved metadata and async behaviour. Retry decorators must not repeat side effects without idempotency.

What are class decorators and closures?Middle

Answer

A class decorator takes a class and returns a modified/replacement class; a function decorator takes a function. This differs from @classmethod. A closure retains enclosing-scope bindings: an evaluator factory may capture a threshold. Watch late binding in loops and shared mutable captured state.

How do you test exception paths without hiding errors?Middle

Answer

A test should trigger a specific condition, assert the exception type and meaningful attributes, and verify state after failure. A broad except or empty catch hides defects. For retryable failures, separately verify attempt count, backoff, and that non-retryable exceptions are not repeated.

What do type hints provide in dynamic Python?Middle

Answer

Type hints document expected contracts and let a static checker catch some errors before runtime. They do not automatically validate values at runtime and do not replace tests. Their greatest value appears at module boundaries, in complex data structures, and during refactoring.

AI and ML fundamentals

How do encoders, decoders and Transformers differ and what are embeddings?Middle

Answer

Transformer is an architecture family using attention. Encoders often produce contextual representations; autoregressive decoders generate subsequent tokens; encoder-decoder models combine encoding and generation. An embedding is a vector representation whose similarity may reflect learned relations. It does not guarantee equivalent meaning or factual correctness; evaluate embeddings on domain data.

Primary sources

  • S12: NIST AI Risk Management Framework (AI RMF 1.0)
  • S28: Attention Is All You Need (NeurIPS 2017)
What ML types exist and what is needed for on-prem LLM hosting?Middle

Answer

Supervised ML learns from labelled targets; unsupervised ML finds structure without those labels; reinforcement learning optimizes behaviour through rewards. On-prem hosting needs licence checks, RAM/VRAM, quantization, serving, concurrency, security and updates. Measure throughput, latency, memory and quality on your tasks.

Primary sources

  • S12: NIST AI Risk Management Framework (AI RMF 1.0)
  • S28: Attention Is All You Need (NeurIPS 2017)
How do guardrails differ from broader AI safety?Middle

Answer

Guardrails are operational controls in a specific system. AI safety is broader: training choices, alignment, evaluations, misuse analysis, governance and incident response. Do not equate a content filter with overall product safety; test bypasses, false blocks and fail-open behaviour.

Prompting and tool calling

When are few-shot examples and stepwise approaches useful?Middle

Answer

Few-shot prompting supplies representative input/output examples; ensure they do not leak from the evaluation set or introduce bias. Break complex tasks into checkpoints and request concise justification. Do not demand hidden chain-of-thought or use it as an oracle; evaluate artifacts, evidence and actions.

Primary sources

  • S21: OpenAI function calling (reviewed 2026-10-06)
How do temperature and top-k affect output?Middle

Answer

Temperature changes the distribution before sampling; top-k retains k candidates. Greater variability may affect answer stability. Not every API supports these parameters; low temperature or a seed does not guarantee full reproducibility. Record configuration and compare repeated runs on identical cases.

Primary sources

  • S21: OpenAI function calling (reviewed 2026-10-06)
How should code-generation prompts be designed?Middle

Answer

Specify language/runtime, interfaces, dependencies, constraints, acceptance criteria and examples. Request a minimal change, runnable tests and explicit assumptions. Validate generated code through compilation, tests, security checks and review; do not run it with production credentials or unrestricted network/filesystem access.

Primary sources

  • S21: OpenAI function calling (reviewed 2026-10-06)
How does structured output differ from executing a tool call?Middle

Answer

Structured output constrains generated data to a schema but does not prove that values are true. A tool call is the model’s proposal to invoke a capability with arguments; the application controls actual execution. Before a side effect, validate, authorise, ensure idempotency, and require human approval for risky actions.

RAG and retrieval

How are faithfulness and pipeline changes evaluated safely?Middle

Answer

Split answers into claims, inspect support/contradictions, count supported claims and citation coverage for source-requiring claims. Review samples with humans. Version the chunker, embeddings, corpus, index and reranker; changing embeddings usually requires reindexing. Compare A/B variants on identical queries and test TTL/invalidation and rollback.

Primary sources

  • S15: Ragas metrics (stable docs reviewed 2026-10-06)
  • S22: Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks (NeurIPS 2020)
How do precision and recall apply to retrieval evaluation?Middle

Answer

Recall measures how much of the required material the system found; precision measures how much of the retrieved material is actually relevant. Increasing top-k often raises recall but adds noise and cost. Calculate metrics on labelled queries and add rank-aware measures when result position matters.

Agents and coordination

What components and types characterize agentic systems?Middle

Answer

Components include perception/context, reasoning/planning, tools/actions, memory, policies and feedback. Classical types are reflex, model-based, goal-based and utility-based; this is a teaching taxonomy rather than a list of modern libraries. Agentic systems select some steps autonomously but need bounded permissions and budgets.

Primary sources

  • S23: ReAct: Synergizing Reasoning and Acting in Language Models (ICLR 2023)
How is agent communication implemented and tested?Middle

Answer

Use typed envelopes, correlation/task IDs, versioning, deadlines, deduplication and explicit ownership. Test duplicate/out-of-order events, missing responses, partial completion and competing writes. Delivery does not imply execution; acknowledgments and business results have different semantics.

Primary sources

  • S23: ReAct: Synergizing Reasoning and Acting in Language Models (ICLR 2023)
When is an agent unnecessary?Middle

Answer

When the action sequence is known and a normal workflow with clear rules and validators can perform it.

MCP and contract testing

How are schema evolution and optional or extra fields tested?Middle

Answer

Adding an optional field may be compatible; new required fields, narrower types or changed semantics may break compatibility. Extra-field behaviour depends on additionalProperties and reader policy. Missing optional fields differ from null. Test old-client/new-server and the reverse, negotiated protocols and business compatibility.

Primary sources

  • S10: Model Context Protocol specification (2026-07-28)
  • S11: MCP server tools (2026-07-28)
How are fail-fast contract tests and error handling built in CI?Middle

Answer

On PRs validate schemas and representative examples, diff required fields/types and replay consumer contracts. Separately test protocol errors, tool execution errors, transport failures and provider rate limits. Retry policy belongs to the implementation: test bounded retries, backoff and idempotency. Block breaking contracts before live evals.

Frameworks for chains and graphs

When should AutoGen or CrewAI use one or several agents and what tests apply?Middle

Answer

One agent: simple-task success and controlled failure when a tool is unavailable. Several agents: correct handoff preserving task IDs and denied cross-role actions. Use multi-agent only when coordination/capabilities require it; branding is not justification. Check APIs and support status before implementation.

Which semantic metrics can be automated?Middle

Answer

Embedding cosine similarity, token overlap and model-based rubrics can help but measure different things. Exact match suits IDs/enums, token overlap misses some semantics and cosine does not prove truth. Combine domain validators, factual checks and human calibration; explain metric limitations in reports.

Evaluation and golden datasets

How is RAG evaluated and which evaluation frameworks exist?Middle

Answer

Separate retrieval, generation and whole-system outcomes. Examples include Ragas, DeepEval, OpenAI Evals/API evals, LangSmith and Langfuse. They differ in datasets, judges, tracing and metrics; they are not interchangeable guarantees. Choose by required assertions, privacy, reproducibility and raw-result export. As of 2026-10-06, OpenAI is moving users away from the deprecated Evals platform toward Datasets/newer evaluation workflows; check the current deprecations page before integration.

GenAI security and privacy

What are major threats and what is jailbreaking?Middle

Answer

Threats include prompt injection, sensitive disclosure, poisoning, unsafe output handling, excessive agency and resource abuse. Jailbreaking attempts to bypass model policies; injection redirects behaviour through untrusted instructions. Mitigate with scoped tools, validation, isolation, access control and monitoring. Filters or system prompts alone are insufficient.

Responsible AI

What ethical principles and privacy challenges matter?Middle

Answer

Translate fairness, transparency, privacy, accountability, safety and human oversight into observable requirements. Risks include unjustified reuse, re-identification, sensitive inference and unequal group quality. Agree on intended use, affected users, appeal/escalation and accountable owners; abstract principles alone are insufficient as test oracles.

Primary sources

  • S12: NIST AI Risk Management Framework (AI RMF 1.0)
  • S19: Azure AI Content Safety overview (docs reviewed 2026-10-06)
How do anonymization and pseudonymization differ?Middle

Answer

Anonymization aims to make re-identification impractical under the relevant threat model; pseudonymization replaces identifiers but permits linkage through additional information. Removing names alone does not ensure anonymity. Check indirect identifiers, rare combinations and logs; consider privacy–utility trade-offs and access to mapping keys.
