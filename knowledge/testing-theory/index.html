How does verification differ from validation?

Answer

Verification checks conformance to a specification; validation checks whether the product is suitable for the user’s needs.

Examples

  • A form may match every specified field yet still prevent the user from completing the real task.

Practice exercises

  1. Give one verification and one validation example for a checkout.
How does regression testing differ from retesting?

Answer

Retesting checks a specific fix; regression testing looks for unintended changes in other behaviour.

Examples

  • After a promo-code fix, retesting repeats the failing scenario while regression checks other checkout calculations.

Practice exercises

  1. For a fixed defect, design one retest and three risk-based regression checks.
What does risk-based testing mean?

Answer

The scope and priority of testing are guided by the likelihood and impact of a problem, together with the available resources.

Examples

  • A payment change receives deeper and earlier testing than a cosmetic change in a rarely visited section.

Practice exercises

  1. Build a strategy for the NiceDice checkout: scope, risks, test levels, environment, data, and exit criteria.
