How does continuous delivery differ from continuous deployment?

Answer

Delivery keeps changes ready for release; deployment automatically releases suitable changes to production.

Examples

  • With delivery, release may require a human decision; deployment releases a successful change automatically.

Practice exercises

  1. Draw a pipeline for both models and mark the human approval point.
How does an image differ from a container?

Answer

An image is a filesystem and configuration template; a container is its running or stopped instance with its own state.

Examples

  • One immutable image can start multiple containers with different environment variables.

Practice exercises

  1. Build an image, run two containers, and compare their configuration and writable state.
How does readiness differ from liveness?

Answer

Readiness decides whether a workload can receive traffic; liveness decides whether it should be restarted as unhealthy.

Examples

  • During warm-up, a pod may be alive but not ready to receive requests.

Practice exercises

  1. Design separate probes for a service with a long cache warm-up.
