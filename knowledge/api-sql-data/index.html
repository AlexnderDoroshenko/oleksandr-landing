Questions and practice

Open a question to see the answer, examples, and exercises.

Why use a transaction?

Answer

So related operations complete as one logical unit with either commit or rollback.

Examples

  • Creating an order and reserving stock should either both complete or both roll back.

Practice exercises

  1. Simulate a failure between two SQL operations and verify the rollback.
Why does an index not always make a system faster?

Answer

It may speed up reads but costs storage and work on writes; value depends on the query plan and data distribution.

Examples

  • An index on a low-selectivity field may be ignored while still slowing inserts.

Practice exercises

  1. Compare EXPLAIN before and after an index, and measure its effect on reads and writes.
What should be checked beyond the HTTP status?

Answer

Response schema and semantics, state changes, authorization, side effects, and repeated-request behaviour.

Examples

  • A 201 does not prove that the resource was stored correctly or that an event was published exactly once.

Practice exercises

  1. For a create endpoint, design checks for contract, state, access, side effects, and retries.
